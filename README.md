# Tamil Selvan K — Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded online; system fonts are used as fallback.

## Included sections
- Intro / hero
- About
- Skills
- Three projects from the resume
- Experience and education
- Research presentations and certifications
- Contact links

## Publish online
### GitHub Pages
1. Create a GitHub repository (for example, `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open repository **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the published URL shown in Settings → Pages.

### Netlify
Drag the extracted folder into Netlify's manual deploy area, or connect the GitHub repository.

## Before publishing
- Confirm the phone number and email are correct and that you want them public.
- Add links to each project repository (the current project illustrations are decorative).
- If you want a real resume download, place your PDF in this folder as `resume.pdf` and add a link to it.
- The cardiac risk project reports “up to 98% accuracy” as stated in the resume; add evaluation details / dataset source before using this metric in a technical interview.
